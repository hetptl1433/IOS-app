## Apple Sleep / Wind Down limitation

**Calendar event is a separate Calendar item. It does not mirror Health's built-in
Sleep Schedule, Wind Down, or the Clock wake alarm.** The app now labels that
source explicitly and explains it in the source information panel.

Apple documents [Sleep event triggers in Shortcuts](https://support.apple.com/guide/shortcuts/apd932ff833f/ios),
[recorded sleep data in HealthKit](https://developer.apple.com/videos/play/wwdc2022/10005/),
and [app-created alarms in AlarmKit](https://developer.apple.com/documentation/alarmkit).
Those sources did not establish a supported API for SPARC to read the forthcoming
Health/Clock sleep timetable. Native automatic mirroring was **not implemented or
verified**; event triggers alone do not supply the advance wake-time forecast
needed to finish charging before the alarm. Manual editing and the existing
Calendar-event sync are the working options.
